# MPEG-DL-TOOL 動画ダウンローダー

**日本語** | [English](README.en.md)

ウェブページの中にある動画を探して、ダウンロードする Windows 用のツールです。
YouTube などの対応サイトはもちろん、別のページに埋め込まれたプレイヤー（iframe）や、JavaScript で後から読み込まれる動画（HLS/DASH 形式）も探し出せます。

> [!IMPORTANT]
> **ご利用前に必ずお読みください**
> - ダウンロードしてよいのは、**ご自身が権利を持つ動画・権利者が許可している動画・利用規約でダウンロードが認められている動画だけ**です。
> - 違法にアップロードされたものと知りながら動画をダウンロードすることは、著作権法で禁止されています（日本の場合）。
> - YouTube など多くのサイトは、利用規約でダウンロードを禁止または制限しています。各サイトの規約を確認してください。
> - ダウンロードした動画を、権利者の許可なく再配布・アップロード・販売しないでください。
> - コピー防止（DRM）のある動画（Netflix、Amazon Prime Video、Disney+ など）には対応していません。
>
> 初回起動時にも同じ注意事項が表示され、同意した場合のみ使えます。あとから画面右上の「ℹ 注意事項」で読み直せます。

## 動作環境

| 項目 | 内容 |
| --- | --- |
| OS | Windows 10 / 11（64ビット） |
| ブラウザ | Microsoft Edge（Windows に標準で入っています）。無い場合は Google Chrome |
| インターネット | 必要（初回起動時に部品を約120MBダウンロードします） |
| 表示言語 | 日本語・English・简体中文・繁體中文・한국어・Español・Français・Deutsch・Português (Brasil) |
| 空き容量 | 約400MB 以上（部品の分。ダウンロードする動画の分は別） |

## ダウンロード

[最新版のダウンロードページ（GitHub Releases）](https://github.com/s-zak-software/MPEG-DL-TOOL/releases/latest) から `MPEG-DL-TOOL-v（バージョン）.zip` をダウンロードし、好きな場所に展開してください。

| zip の中身 | 内容 |
| --- | --- |
| `MPEG-DL-TOOL.exe` | 本体 |
| `README_ja.txt` / `README_en.txt` | この説明書（日本語・英語） |
| `TERMS_ja.txt` / `TERMS_en.txt` | 利用規約（日本語・英語） |
| `THIRD_PARTY_LICENSES.txt` | 本体に含まれているソフトウェアのライセンス |

インストールは不要です。`MPEG-DL-TOOL.exe` を好きな場所に置いて使えます。

ダウンロードページには、各ファイルの SHA-256（ファイルの指紋）を載せています。PowerShell で `Get-FileHash MPEG-DL-TOOL.exe` を実行して表示される値と同じなら、ファイルが途中で書き換えられていないことを確かめられます。

## はじめて起動するとき

1. `MPEG-DL-TOOL.exe` をダブルクリックします
2. 「Windows によって PC が保護されました」と表示された場合は、「詳細情報」→「実行」を押してください
   - 電子署名の付いていない exe で表示される警告です。ウイルス対策ソフトが誤って警告することもあります
3. 表示する言語を選びます（最初は English が選ばれています。日本語は一覧の一番下にあります）
   - あとから画面右上の **「🌐 言語」** で変えられます。変えた言語は再起動すると反映されます
4. 利用上の注意が表示されます。内容を読み、「同意して使う」を押してください
5. 動画の処理に必要な部品（yt-dlp、ffmpeg など）を自動でダウンロードします。終わるとメイン画面が開きます

2回目以降は、すぐにメイン画面が開きます。

## 使い方

1. 動画があるページの URL を貼り付けます（「📋 貼り付け」ボタンも使えます）
2. **「🔍 動画を探す」** を押すと、見つかった動画が一覧に表示されます
3. 欲しい動画にチェックを入れて（行をクリックで切り替え）、**「⬇ 選択した動画をダウンロード」** を押します
   - 「保存ファイル名」の欄をクリックすると名前を変えられます（Enter で確定、Esc で取り消し。拡張子は自動で付きます）
   - 「状態」の欄に進み具合が表示され、終わった行は緑色になります
   - 終わった行をダブルクリックすると、保存したファイルの場所が開きます
   - 保存先に同じ名前のファイルがあるときは、上書きせずに「名前 (2)」のように番号を付けて保存します
4. 保存先のフォルダは **「📂 ダウンロードフォルダを開く」** で開けます（初期設定は「ダウンロード」フォルダ）

YouTube など対応サイトの動画ページなら、「URL を直接ダウンロード」でも保存できます（動画を探す手順を省くぶん速く終わります）。

### 処理中でも次々に追加できます

- 解析やダウンロードの途中でも、新しい URL を入れて「動画を探す」「URL を直接ダウンロード」を押せます。押すと入力欄が空になるので、続けて次の URL を貼り付けられます
- 解析は1件ずつ順番に行い、結果は一覧の下に追加されます
- ダウンロードは順番待ちの列に並び、「同時ダウンロード数」（1〜5）の数まで同時に進みます
- **「見つかった動画を自動でダウンロード」**（初期設定でオン）にチェックが入っていると、解析が終わったときに一番有力な動画（一覧で最初からチェックが付いているもの）を自動でダウンロードします。ダウンロード済み・予約済みの同じ動画は飛ばします
- 行を右クリックすると、その行だけ中止・再試行・名前の変更・一覧から削除ができます。「すべて中止」を押すと、解析待ちも含めて全部止まります
- 「完了した行を消去」で、終わった行をまとめて一覧から消せます

### 形式

| 形式 | 内容 |
| --- | --- |
| 最高画質 (MP4) | 一番高い解像度。同じ解像度なら、多くの機器で再生できる H.264 を優先 |
| 1080p / 720p まで (MP4) | 解像度の上限を指定（ファイルを小さくしたいとき） |
| 音声のみ (MP3) | 音声だけを MP3（192kbps）で保存 |

### 見つからないとき：手動モード

「ブラウザを表示して手動で再生」にチェックを入れて「動画を探す」を押すと、ブラウザの画面が開きます。
ログイン・広告を閉じる・再生ボタンを押すといった操作を自分で行い、動画の再生が始まったら「キャプチャ終了」を押してください（ブラウザを閉じても終了します）。
ログイン状態はこのツール専用の場所に保存されるので、次回からは自動の解析でも使われます。

## アップデート

画面右上の **「🔄 アップデート」** を押すと、部品（yt-dlp・ffmpeg・deno・Playwright など）の更新を確認して、まとめて更新できます。

- 起動して数秒後に自動で確認し、更新があるとボタンが「🔄 アップデートあり (件数)」に変わります
- 更新はダウンロードしたあと、再起動すると反映されます。処理中のときや「いいえ」を選んだときは、次回起動時に自動で反映されます
- サイト側の仕様が変わってダウンロードできなくなったときは、まずアップデートを試してください

ツール本体（exe）の自動更新はありません。新しい版が公開されたら、exe を差し替えてください（設定や部品はそのまま使えます）。

## うまくいかないとき

- **ダウンロードできなくなった** … 「🔄 アップデート」で部品を最新にしてください
- **「アクセスが拒否されました (403)」と出る** … 手動モードで動画を再生してから、もう一度試してください
- **動画が見つからない** … 手動モードを試してください。DRM で保護された動画は見つかりません
- **調子が悪い** … `%LOCALAPPDATA%\MPEG-DL-TOOL\lib` フォルダを削除して起動し直すと、部品を入れ直します
- 予期しないエラーは `%LOCALAPPDATA%\MPEG-DL-TOOL\error.log` に記録されます。問い合わせの際に添えていただくと原因を調べやすくなります（閲覧したページの URL が含まれることがあります）

## 通信とデータの保存について

**インターネットとの通信**
- 部品のダウンロードとアップデートの確認のために、PyPI（Python の公式配布サイト、pypi.org）に接続します。ダウンロードした部品は、PyPI が公開している SHA-256（ファイルの指紋）と照合して、通信途中で書き換えられていないか確かめてから使います
- 動画を探す・ダウンロードするときは、指定したページと、その動画の配信元に接続します
- 利用状況などを開発者に送る機能はありません

**パソコンに保存されるもの**（すべて `%LOCALAPPDATA%\MPEG-DL-TOOL` の中）

| 場所 | 内容 |
| --- | --- |
| `lib` | 部品（yt-dlp、ffmpeg など） |
| `browser-profile` | 解析用ブラウザのデータ（サイトのログイン状態・Cookie など） |
| `error.log` | エラーの記録 |
| `settings.json` | 設定（表示言語） |
| `notice_accepted` | 利用上の注意に同意した記録 |

`%LOCALAPPDATA%` は、エクスプローラーのアドレス欄にそのまま入力すると開けます。

## アンインストール

1. `MPEG-DL-TOOL.exe` を削除します
2. `%LOCALAPPDATA%\MPEG-DL-TOOL` フォルダを削除します（部品・ログイン状態などがすべて消えます）

旧名称（DL-Tool）の頃から使っていた場合、`%LOCALAPPDATA%\DL-Tool` が残っていれば同様に削除してください。
